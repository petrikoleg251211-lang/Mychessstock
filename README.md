# Stockfish Review — Android Chess Analysis Application

Повноцінний нативний Android-застосунок для глибокого аналізу шахових партій на базі офіційного рушія **Stockfish 19**. 
Застосунок працює повністю локально та автономно, не вимагає платної підписки, облікового запису або постійного інтернет-з'єднання.

---

## 🌟 Інтеграція справжнього Stockfish 19

- **Джерело рушія**: Офіційний репозиторій [official-stockfish/Stockfish](https://github.com/official-stockfish/Stockfish) (Реліз `sf_19`).
- **Архітектура**:
  - `arm64-v8a`: Офіційний нативний 64-бітний ELF-виконуваний файл `stockfish-android-arm64-universal`, повністю оптимізований під процесори ARM64 (включно з **Samsung Galaxy S25 Ultra** / Snapdragon 8 Elite з ядрами Oryon).
  - `x86_64`: Офіційний нативний 64-бітний файл для емуляторів та робочих середовищ.
- **Вбудована нейромережа (NNUE)**:
  - Рушій скомпільовано з вбудованими бінарними вагами нейромереж (`nn-1a298aa575a0.nnue` та допоміжними шарами), що усуває потребу завантажувати сторонні файли мережі під час запуску.
- **Спосіб пакування на Android**:
  - Розміщено у `app/src/main/jniLibs/arm64-v8a/libstockfish.so` та `app/src/main/jniLibs/x86_64/libstockfish.so`.
  - У `app/build.gradle.kts` налаштовано `useLegacyPackaging = true`, що зобов'язує Android PackageManager видобувати виконуваний файл у системну директорію `applicationInfo.nativeLibraryDir` із правами на виконання (`r-xp`).
  - Реалізовано багаторівневий механізм пошуку бінарного файлу (`nativeLibraryDir`, `filesDir`, динамічне видобування з APK через `ZipFile` у разі нестандартного встановлення).
- **UCI-протокол**:
  - Повний цикл команд: `uci` (перевірка `uciok` та розпізнавання версії `Stockfish 19`), `isready` (`readyok`), `ucinewgame`, `position fen ... moves ...`, `go depth / movetime`, `stop`, `quit`.
  - Синхронізація I/O-потоків через корутинні `Mutex` для унеможливлення взаємних блокувань і гонок потоків під час скасування пошуку.
- **Прозорий статус рушія**:
  - Застосунок чітко показує у шапці дошки та на екрані налаштувань, який саме рушій активний: **Stockfish 19 (Official NNUE Engine)** чи резервний режим Lite.

## ⚙️ Оптимізація для Samsung Galaxy S25 Ultra

Застосунок надає розширене керування параметрами апаратного прискорення:
- **Кількість потоків (Threads)**: 1, 2, 4, 8 потоків (використання всіх ядер Oryon Snapdragon 8 Elite).
- **Обсяг таблиці хешування (Hash MB)**: 32, 64, 128, 256 МБ (з урахуванням 12–16 ГБ оперативної пам'яті).
- **MultiPV**: 1–3 одночасні найкращі лінії для вивчення альтернативних варіантів.
- **Профілі аналізу**:
  - **Гросмейстер S25 Ultra (Grandmaster)**: Глибина 24–30 ply (2000 мс/хід).
  - **Збалансований (Balanced)**: Глибина 18 ply (1200 мс/хід).
  - **Швидкий (Fast)**: Глибина 14 ply (600 мс/хід).

## 📊 Можливості Game Review

- **Точність гравців (Accuracy %)**: Окремий розрахунок для білих та чорних на базі сигмоїдної моделі ймовірності перемоги.
- **Категоризація ходів**:
  - 💎 **Геніальний (`!!`)**: Тактична жертва зі збереженням переваги.
  - ⭐ **Найкращий (`★`)**: Перша лінія Stockfish.
  - ✓ **Відмінний**: Втрата менше 3.5% шансів.
  - • **Хороший**: Надійний практичний хід.
  - 📖 **Теорія (Book)**: Дебютний хід із бази ECO (понад 50 систем).
  - ⚠️ **Неточність (`?!`)**: Втрата 7–16% переваги.
  - ❓ **Помилка (`?`)**: Втрата 16–32% переваги.
  - ❌ **Зевок (`??`)**: Втрата понад 32% переваги.
- **Інтерактивний графік переваги (EvalGraph)**: Перехід до будь-якої позиції одним дотиком.
- **Розбір помилок**: Швидкий перехід до зевків і неточностей.

## 🛠 Технологічний стек

- **Мова**: Kotlin 2.2.10
- **UI**: Jetpack Compose (Material Design 3)
- **Архітектура**: Clean MVVM + Repository Pattern + Kotlin Coroutines & StateFlow
- **База даних**: AndroidX Room 2.7.0 з KSP
- **Рушій**: Official Stockfish 19 (ARM64-v8a / x86_64, NNUE)
- **Тестування**: JUnit 4, Robolectric

## 📦 Інструкція зі збирання та запуску

### Відкриття в Android Studio:
1. Запустіть Android Studio.
2. Оберіть **File -> Open...** та відкрийте кореневу папку проєкту.
3. Дочекайтеся синхронізації Gradle.

### Збирання Debug APK:
```bash
gradle :app:assembleDebug
```
Готовий APK створюється за шляхом:
`app/build/outputs/apk/debug/app-debug.apk`

### Запуск модульних тестів (включно з тестом справжнього Stockfish):
```bash
gradle :app:testDebugUnitTest
```
