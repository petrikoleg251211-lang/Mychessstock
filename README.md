# Stockfish Review — Android Chess Analysis Application

Повноцінний нативний Android-застосунок для глибокого аналізу шахових партій на базі рушія **Stockfish**. 
Застосунок працює повністю локально та автономно, не вимагає платної підписки, облікового запису або постійного інтернет-з'єднання.

---

## 🌟 Основні можливості

1. **Інтерактивна шахова дошка**:
   - Повна реалізація правил FIDE: рокіровка (O-O, O-O-O), взяття на проході (en passant), перетворення пішаків (Q, R, B, N).
   - Відображення шаху, мату, пату та недостатності матеріалу.
   - Підсвічування останнього ходу та легальних ходів (точки для тихих ходів, кільця для взяття).
   - Стрілки найкращого ходу (Best Move Arrow) на дошці.
   - Оцінювальна шкала переваги (Evaluation Bar) з числовим значенням у пішаках (+1.45) або матом (M3).
   - Обертання дошки (White / Black perspective).

2. **Інтеграція Stockfish через UCI**:
   - Підтримка повного циклу команд UCI: `uci`, `isready`, `ucinewgame`, `position fen ... moves ...`, `go depth / movetime`, `stop`.
   - Читання метрик: `depth`, `seldepth`, `score cp / mate`, `nodes`, `nps`, `time`, `multipv`, `pv`.
   - Профілі навантаження:
     - **Гросмейстер (Grandmaster)**: Глибина 22+, 1600 мс/хід.
     - **Збалансований (Balanced)**: Глибина 18, 1000 мс/хід.
     - **Швидкий (Fast)**: Глибина 14, 600 мс/хід.
   - Налаштування кількості потоків (Threads 1–4), розміру хешу (Hash 32–128 MB) та MultiPV (1–3 альтернативні лінії).
   - Нативний міст із безшовним вбудованим рушієм для 100% стабільності на всіх архітектурах процесорів.

3. **Game Review (Огляд партії)**:
   - Автоматичний розрахунок точності (Accuracy %) окремо для білих і чорних за логістичною моделлю ймовірності перемоги.
   - Прозора система класифікації ходів:
     - 💎 **Геніальний (Brilliant `!!`)**: Тактична жертва фігури зі збереженням вирішальної переваги.
     - ⭐ **Найкращий (Best `★`)**: Головний вибір рушія.
     - ✓ **Відмінний (Excellent)**: Втрата менше 3.5% переваги.
     - • **Хороший (Good)**: Надійний практичний хід.
     - 📖 **Теорія (Book)**: Дебютний хід із бази ECO (понад 50 класичних дебютів).
     - ⚠️ **Неточність (Inaccuracy `?!`)**: Втрата 7–16% шансів на перемогу.
     - ❓ **Помилка (Mistake `?`)**: Втрата 16–32% шансів на перемогу.
     - ❌ **Зевок (Blunder `??`)**: Втрата вирішальної переваги або матеріалу.
   - Інтерактивний графік переваги (EvalGraph) з можливістю переходу до будь-якого моменту партії одним дотиком.
   - Список критичних помилок із миттєвим переходом до позиції для тренування.

4. **Імпорт та експорт PGN**:
   - Імпорт `.pgn` через системний файловий менеджер Android.
   - Вставка PGN тексту з буфера обміну.
   - Підтримка партій Chess.com і Lichess з метаданими (гравці, рейтинг, подія, дата, результат, годинники).
   - Експорт партії з коментарями та комп'ютерними оцінками в стандартний PGN.

5. **Локальна бібліотека (Room Database)**:
   - Збереження партій та результатів аналізу в локальній базі даних SQLite (Room).
   - Передвстановлені шедеври світових шахів: "Партія століття" (Бирн — Фішер), "Безсмертна партія Каспарова" (Каспаров — Топалов), "Оперна партія" (Морфі).

6. **Двомовна локалізація**:
   - Повна підтримка української та англійської мов з автоматичним визначенням і швидким перемикачем у шапці застосунку.

## 🛠 Технологічний стек

- **Мова**: Kotlin 2.2.10
- **UI**: Jetpack Compose (Material Design 3)
- **Архітектура**: Clean MVVM + Repository Pattern + Kotlin Coroutines & StateFlow
- **База даних**: AndroidX Room 2.7.0 з KSP
- **Рушій**: Stockfish UCI Protocol Engine
- **Тестування**: JUnit 4, Robolectric

## 📦 Інструкція зі збирання та запуску

### Відкриття в Android Studio:
1. Запустіть Android Studio (Giraffe, Hedgehog, Koala або новішу).
2. Оберіть **File -> Open...** та виберіть кореневу директорію проєкту.
3. Дочекайтеся завершення Gradle Sync.

### Збирання Debug APK:
```bash
gradle :app:assembleDebug
```
Готовий APK буде створено за шляхом:
`app/build/outputs/apk/debug/app-debug.apk`

### Запуск модульних тестів:
```bash
gradle :app:testDebugUnitTest
```
